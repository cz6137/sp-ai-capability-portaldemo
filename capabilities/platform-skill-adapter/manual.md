# 使用手册

需要已有 Python 3.10 或以上，检查器只用标准库，不安装依赖。命令从本 Skill 包根目录运行。支持普通目录和未加密 ZIP；不支持 RAR、嵌套压缩包、可执行二进制或链接文件。单文件上限 20 MB、总量 100 MB、文件数 2000，适用于能力源码和资料接入，不适用于依赖缓存或构建目录。

inspect：只读取指定输入，在新路径写 JSON 报告。返回码 0 表示静态检查通过，2 表示缺项/阻断，1 表示调用失败。没有清单时可以检查文件安全，但会报告缺少清单。报告里的 `readingPlan` 是机器阅读顺序：先入口指令和它引用的规则，再读手册及补充资料，脚本只在核对实现时读取。上传者只交原始目录或 ZIP，不需要另填一份能力说明问卷。`content` 与 `packageItems` 是包内实物；`packageWarnings` 和 `warningCandidates` 是机器整理执行约束的证据，不直接铺到使用者页面；`questions` 只询问材料中无法得知的平台登记事实。清单按内容识别，不锁定文件名，也不要求特定目录结构。

机器应根据 readingPlan 归纳什么任务需要该 Skill、应交材料、实际处理步骤、产物和不能自行定案的情况。归纳必须有包内依据；“提高效率、保障质量、适合相关人员”等泛化文字视为未填写。草稿把执行约束写入 `quality.warnings`，把自动提取、用户确认或用户修改的字段写入 `provenance`。包里不存在的维护人、审核记录和效果承诺一律留空。

draft：生成新目录，其中 draft-capability.json 保留缺失字段，ADAPTATION-REPORT.json 列出缺项。即使原包是已发布，也降为 DRAFT 并关闭在线处理。不复制外部文件。清单里空着的 `packageItems` 按包内实际文件填上，人工已填过的不覆盖。补齐字段后再使用 prepare。

prepare：要求给定 Manifest 与实际文件一致；通过后生成可复查的目录。所有状态降为 DRAFT、审核人和审核日期移除、在线默认关闭。原包已有清单时，只有内容与待输出草稿一致才原字节保留；否则停止并报告冲突。输入清单若叫别的名字（如 skill-manifest.json），输出的平台清单一律写成 capability.json 并保留原文件。CHECKSUMS.json、ADAPTATION-REPORT.json 同名（含大小写变体）也会阻断。请人工在单独工作副本中处理冲突，不要删除或改写原始材料，也不要自动重命名被业务引用的文件。脚本文件可复制，但始终有“需人工审查”提示，不会执行。

包内 Schema 校验器实现当前平台 Schema 使用的关键字，并对未知校验关键字报错。它不替代前端/Java 预检，平台导入前仍须使用管理页再次校验。敏感值检测是启发式，不能证明包内不存在秘密；对二进制资料和内容授权仍需人工复核。

安装：解压到使用者选择的受控工作目录，以客户端支持的方式加载本包 SKILL.md；仅运行已审阅的本包 adapt.py。卸载时由使用者删除安装副本，不自动删除源材料或交付成果。

支持头部名称的普通字符串、单双引号及描述的 | / > 多行写法，保留 SKILL.md 原字节。其他复杂 YAML 写法可能报告不支持，需要人工核对，不自动改写。格式化限于平台清单和交付包装，不保证业务效果；整理后应核对相对引用并在受控环境验收。目录联接及其他 Windows 重解析点在 Python 3.10+ 均拒绝，包含输入和输出的祖先路径。
