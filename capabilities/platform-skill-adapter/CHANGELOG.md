# 平台适配变更记录

## 1.2.1 · 2026-09-16

允许平台能力标识与外部 Skill 原始入口名称不同。原始 `SKILL.md` 保持不变，仍要求其声明名称和说明；平台可使用符合目录命名的独立 slug。

## 1.2.0 · 2026-09-16

接入方式改为“人给资料，机器读包”：报告新增 `readingPlan`，优先读取入口指令和它引用的规则，再读手册与补充资料。机器据此归纳使用时机、输入、处理步骤、产物和不能自行定案的情况；不再把每条规则或弱关键词命中都变成上传者问卷。

详情页不再展示“适不适合我”“使用前先看”等抽象区块。页面固定回答什么情况需要这个 Skill、交什么资料、机器怎么处理、拿回什么；长限制清单转入折叠的机器执行约束，供执行与维护审计使用。

## 1.1.2 · 2026-09-16

减少警告误分类：只从说明类文本自动提取面向使用者的明确禁止、限制和风险句；代码、JSON、表格及 HTML 模板中的命中不直接发布。仅因“待确认”等弱关键词命中的普通流程句进入 `warningCandidates`，由管理员确认类别后再决定是否写入详情页。

详情页默认展示前三条限制，其余内容通过列表底部的“展开全部/收起”控制查看，避免展开按钮夹在警告卡片中间。

## 1.1.1 · 2026-09-16

修复清单已有警告时跳过整条包内警告抽取的问题。现在保留已有内容，并按警告原文、来源文件和行号去重补齐机器摘录；重复运行不会继续增加相同条目。七个现有能力清单已重新同步，共保留 105 条有出处的警告。

权威 Schema 仍只在仓库 `contracts/` 中维护，同时由同步脚本生成适配器包内副本并检查漂移。源目录和正式构建的 ZIP 均可独立运行；副本缺失时会明确报告 `SCHEMA_UNAVAILABLE`，不再只显示无信息量的 `FileNotFoundError`。

## 1.1.0 · 2026-09-16

去掉了对现有几个包的适配假设。清单不再按文件名识别（原先固定找 capability.json，叫 skill-manifest.json 的包会被判为缺清单），改为按根目录 JSON 是否含 schemaVersion 与 kind 判定，多份像清单时报 MANIFEST_AMBIGUOUS 交人工确认。入口校验不再锁定 SKILL.md，任意根目录 Markdown 只要 frontmatter 声明了 name（或 title）与 description 即视为入口。

packageItems 不再固定为一条 SKILL.md，改为按包内实际文件生成：目录文件少则逐条列出，超过 10 个按顶层目录聚合成计数（如「图片 358 个，其他文件 31 个」）。每条说明只取自文件自己的标题、脚本作者写在开头的注释或 docstring、或文件名本身，抄不到就留空并列入 needsDetail，不再出现「随包实际文件」这类占位话术。

新增包内警告摘录：从包内所有文本文件按否定词与风险词逐字摘出警告与限制句，带出处文件与行号，写入清单 `quality.warnings`，并用 `provenance` 标记为机器摘录。此前手册里「不要执行包内脚本」「样例输出不能作为验证记录」「依赖外部 CDN，并非离线成品」这类话在平台上完全不可见。报告保留 content 与 packageItems 两段，并生成引用原句的问题单供维护人确认。

去掉了两处凭空补全：草稿的在线配置不再预填 route 与 maxFileSizeMB: 20，改为空值与 0；清单里空着的 packageItems 按包内实际文件填上，人工已填过的不覆盖。

因 packageItems 可能只带 name 而缺 detail，schema 的 item 不再要求 detail，packageDelivery 的 packageItems 不再要求至少一项。前端、后端和适配器现已统一读取仓库中的权威 Schema，前端详情页也不再显示没有真实说明的占位条目。

## 1.0.1 · 2026-09-05

使用用户提供的两个外部 Skill 回归，修复完整中文凭据占位符误报。只接受明确的完整占位表达，不允许真实值因夹带环境变量或脱敏标记而绕过检查。输出始终为草稿，不执行外部脚本。

## 1.0.0 · 2026-09-05

本次按项目 Capability Manifest 2.1、前端执行器注册表与用户接入要求新编；静态检查脚本不执行外部文件。

统一入口清单保持草稿，中文说明和环境约束已补齐，正式业务验证仍待执行。

## 1.0.2 · 2026-09-08

同名平台输出文件冲突停止，保留普通文件原字节；兼容常见带引号和多行描述头部；补齐 Python 3.10+ Windows 重解析点检测。管理员专用入口提供下载和说明。
