# 文档转换回归用例

以下是测试方案，尚不是业务验收记录。使用脱敏或合成文件，四个方向都核对中文、段落、标题、列表、表格、链接与代码块。

| 输入 | 操作 | 应检查 |
| --- | --- | --- |
| sample.md | Markdown→DOCX/PDF | 文件可打开，标题层级正确，长文本不裁切 |
| 上一步 DOCX | DOCX→Markdown | 中文、表格、列表和代码内容仍可读 |
| 文本型 PDF | PDF→Markdown | 多页阅读顺序、断行、页码混入等情况 |
| 图片型 PDF | PDF→Markdown | 明确文本提取限制，不返回虚构内容 |
| 空、损坏、错误扩展名、超过 20MB 文件 | 对应方向 | 显示错误，旧结果不冒充新输出 |
| 公司复杂模板 Word/PDF | 对应方向 | 页眉页脚、合并单元格、分栏、图文混排人工对照 |

记录：输入文件哈希、操作方向、浏览器版本、执行时间、输出文件、结果差异、复核人、结论及证据位置。不填写预计处理时间或虚构通过人。
