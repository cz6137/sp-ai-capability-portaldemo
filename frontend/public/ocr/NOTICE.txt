Browser-local OCR runtime

This directory contains redistributed runtime assets used by the image OCR tool:

- Tesseract.js worker and WebAssembly core
- Simplified Chinese and English Tesseract language data

are recorded in capabilities/image-ocr/SOURCES.md.
